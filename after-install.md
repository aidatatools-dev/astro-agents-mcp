Astro Agents is connected: 16 astrology tools from https://astro-agent.dev/mcp (no account, no API key), plus the
`astrology` skill. Start a new session, then ask for a birth chart, a horoscope, a kundli or a panchang with a local
date, time and place.

Each client gets 3 free tool calls. After that a tool explains how to pay per call over REST (x402 or MPP);
nothing is ever charged over MCP. `astro_catalog` is free and lists every tool with its price.
